Questions Fréquemment Posées

Quel est le délai de livraison?

Les délais varient selon le vendeur. Consultez la page produit pour voir le délai estimé.

Puis-je retourner un article?

Les retours se discutent directement avec le vendeur (conditions et delais). Vendoscity ne gere pas les remboursements.

Quelles sont les méthodes de paiement?

La commande se fait sur Vendoscity. Le paiement se fait ensuite hors plateforme directement entre acheteur et vendeur selon ce que vous convenez.

Comment créer un compte vendeur?

Créez d'abord un compte client, puis demandez l'accès vendeur via les paramètres.
